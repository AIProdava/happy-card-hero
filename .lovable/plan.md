# План: Свързване на проекта с GitHub

## Цел
Да се активира двупосочна GitHub синхронизация за текущия Birthday Cards проект, така че кодът да се пази и в твое GitHub repository.

## Какво предстои

### Стъпка 1: Стартиране на GitHub sync от Lovable UI
- Отвори Plus (+) менюто в чат полето (долу вляво).
- Избери **GitHub → Connect project**.
- Авторизирай Lovable GitHub App в GitHub.
- Избери акаунт/организация, където да се създаде repo-то.
- Кликни **Create Repository** в Lovable.

### Стъпка 2: Проверка след свързване
- Проверка дали кодът е качен в новото GitHub repo.
- Проверка дали `git remote -v` в Lovable Code Editor показва GitHub URL.
- Потвърждение, че двупосочният sync работи (промени в Lovable отиват в GitHub и обратно).

### Стъпка 3: Документиране на repo-то (по желание)
- Ако е необходимо, добавяне/актуализиране на `README.md` с кратко описание на проекта на български и/или английски.

## Бележки
- GitHub sync е функция на Lovable UI — самият процес на свързване става през интерфейса, не чрез код.
- След свързване можеш да клонираш repo-то локално, да пушваш промени от IDE и да ги виждаш в Lovable в реално време.
- Ако вече имаш съществуващо GitHub repo, Lovable не поддържа директен import — трябва да се създаде ново repo през Lovable и при нужда да се прехвърли код ръчно.
