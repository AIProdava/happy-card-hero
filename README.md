# Birthday Card Creator (56)

Create Birthday Cards app: enter a name -> choose a card image -> generate a greeting card -> share the card by URL. The card consists of image + text "Happy birthday, {name}".

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://happy-card-hero.lovable.app
